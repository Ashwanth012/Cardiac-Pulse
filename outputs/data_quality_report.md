## 1. Decisions that define the dataset

| Decision | Rule |
|---|---|
| Forecasting target | `admissions` = **raw** number of rows in `HDHI Admission data.csv` whose resolved D.O.A is that day. Duplicates are **not** removed. |
| Date resolution | D.O.A resolved with the `month year` column (step 1): 15,757 rows, 0 unresolved, 0 disagreements. |
| Calendar | One row per day 2017-04-01 .. 2019-03-31: **730 rows**, unique, contiguous. Days with no rows would be kept as 0 (there are **0** such days). |
| Not predictors | D.O.D, duration of stay, ICU days, outcome, laboratory values, demographics, comorbidities. Emergency/OPD counts and de-duplicated counts are **analysis / sensitivity columns only** (see `clean_daily_columns.csv`). |
| Weather | Open-Meteo is the primary weather source (complete). Pollution-station temperature/humidity kept as `station_*` cross-check columns only. |
| Log actions | `corrected` = value changed to a confidently recovered value; `set_missing` = invalid value replaced by NaN; `imputed` = NaN filled by linear interpolation (gaps <= 3 days); `flagged` = value **kept unchanged** and recorded for investigation. |

## 3. Duplicate analysis (nothing removed)

Definitions:
* **Exact duplicate**: identical to an earlier row in every column except `SNO`, comparing the *resolved* D.O.A/D.O.D (the same record is sometimes typed in the other date order).
* **MRD+D.O.A repeat**: same `MRD No.` and same resolved admission date as an earlier row.
* **Near duplicate**: an MRD+D.O.A repeat that is *not* an exact duplicate (some clinical fields differ).
* **Overlapping stay**: same patient, a *different* later admission date that falls inside the previous stay (flag only).

### Impact on the daily series
Total rows 15,757 -> 14,872 without exact duplicates
(5.6%) -> 14,399 with one row per MRD+D.O.A
(8.6%).
In Jan-Mar 2019 the raw mean is 26.63 vs 23.77 (exact) and
23.24 (MRD+D.O.A). Exact duplicates are 0.0-1.2% of rows per month
in Apr-Dec 2017 but 1.0-15.8% from Jan 2018 (MRD+D.O.A repeats:
0.2-10.0% vs 3.9-19.5%). The duplication rate
therefore varies over time and adds level shifts to the raw target that are not clinical. They are part of what the harness scores,
so forecasting models must track the recent level of the raw series rather than assume a stable duplication rate.
